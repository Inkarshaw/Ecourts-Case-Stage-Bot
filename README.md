# eCourts Case Stage Telegram Bot

Cloud prototype for Telegram -> eCourts -> CAPTCHA screenshot -> manual CAPTCHA reply -> case-stage lookup.

## Telegram input
`CC 1001 2025`

## Railway variable
`TELEGRAM_BOT_TOKEN`

The first deployment validates cloud Chromium access and CAPTCHA screenshot delivery. Live eCourts selectors are calibrated after that test.
